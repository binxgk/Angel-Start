# angel Start · 应用快捷启动器

一个基于 PySide6（Qt6）打造的桌面应用快捷启动工具，帮助你把常用的程序、文件、文件夹和网址集中管理，用分组、搜索、快捷键和托盘一键唤起，告别堆满桌面的图标。

> 当前版本：v1 ｜ 主要面向 Windows 平台（全局热键、托盘、开机自启均基于 Windows API）

---

## ✨ 功能特性

### 应用管理
- 通过「浏览」添加 **程序 / 文件 / 文件夹**，或直接把文件、网址 **拖拽进内容区** 即可创建快捷方式。
- 支持添加 **网页 URL**，自动使用浏览器默认图标。
- 每个应用可自定义 **名称、图标、备注**，并指定所属分组。

### 分组管理
- 左侧边栏按分组导航，支持 **新建 / 重命名 / 删除分组**。
- 提供「分组排序」对话框，可拖拽调整顺序或设置排序序号（数字越小越靠前）。

### 拖拽与排序
- 内容区图标支持 **内部拖拽排序**，自由调整应用排列。
- 支持 **外部文件拖入**，拖文件或链接即可快速新增快捷方式。

### 搜索过滤
- 顶部搜索框按 **名称 / URL / 备注** 实时筛选，回车直接启动首个匹配项。

### 快捷键启动
- 为每个应用绑定 **全局热键**，即使窗口最小化也能一键启动。

### 系统托盘
- 关闭/最小化到系统托盘，点击托盘图标恢复窗口，并可通过托盘菜单操作。

### 主题切换
- 内置 **浅色 / 深色** 两套极简扁平化主题，一键切换，图标采用线性 SVG。

### 背景图轮播
- 中间内容区支持 **随机轮播背景图**：把图片放进 `data/backgrounds/` 文件夹，启动器自动作为背景，保持比例裁剪铺满（壁纸「填充」效果）。
- 轮换间隔可在「设置 → 背景轮播间隔」调整（单位：秒，默认 30）。
- 文件夹为空或无图片时，回退为纯色背景；侧边栏与顶栏保持白色不透明。

### 启动日志
- 自动记录每次启动事件到 `data/launch_log.json`，可在「日志」页 **搜索、筛选、导出 CSV、清空**。

### 数据备份与恢复
- 设置中支持 **自动备份**（每次启动 / 每天 / 每周 / 每月），可指定备份目录、自动清理旧备份并保留最近 N 份。
- 支持 **手动备份到文件 / 从文件恢复**，方便迁移与回滚配置。

### 开机自启动
- 通过注册表写入自启项，开机后自动运行。

## 🛠 技术栈

- **语言**：Python 3
- **GUI**：PySide6（Qt 6）
- **打包**：PyInstaller 6.x
- **图标**：本地文件图标 + 网络图标下载缓存（`IconManager`）

主要依赖见 `requirements.txt`：
```
PySide6==6.10.1
pyinstaller==6.17.0
pywin32-ctypes==0.2.3
...
```

---

## 🚀 安装与运行（从源码）

1. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
2. 运行主程序：
   ```bash
   python quicklauncher.py
   ```

> 说明：程序首次启动会自动创建 `data/` 目录（含启动日志、背景图文件夹等）与配置文件。

---

## 📦 打包为独立 EXE

仓库已提供 `快捷启动器.spec`，直接用 PyInstaller 打包：

```bash
pyinstaller 快捷启动器.spec
```

打包产物位于 `dist/快捷启动器.exe`（约 45MB，已内嵌多分辨率 `app.ico` 图标）。

---

## 📁 目录结构

```
快捷启动器源码/
├── quicklauncher.py      # 主程序
├── theme.py              # 主题（颜色 / QSS / SVG 图标）
├── 快捷启动器.spec       # PyInstaller 打包配置
├── app.ico               # 程序图标（16~256 多分辨率）
├── requirements.txt      # 依赖
├── _arrows/              # 内置 SVG 图标资源
└── data/                 # 运行时生成：配置、启动日志、backgrounds/ 背景图
```

---

## 📝 数据与配置

- **配置文件**：`data/` 下的 JSON（应用列表、分组、设置等）。
- **背景图**：放入 `data/backgrounds/`，支持的格式包括 png / jpg / jpeg / bmp / webp / gif。
- **启动日志**：`data/launch_log.json`，可在软件内查看与导出。
